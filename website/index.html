Steel

Steel (.steel) is a small programming language written in Rust. You can run files directly with the built-in interpreter or stack VM, or compile single files and multi-file projects into C11, C++20, Rust, Go, Python 3, JavaScript, TypeScript, or Lua.

Working with other codebases

When you compile a folder or a file with import statements, Steel keeps every module as its own file instead of flattening the project into one giant output. Pass --bundle if you specifically want a single standalone file. 

steel compile myproject cpp
steel compile myproject ts
