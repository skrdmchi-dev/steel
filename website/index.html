Steel

Steel (.steel) is a small programming language written in Rust. You can run files directly with the built-in interpreter or stack VM, or compile single files and multi-file projects into C11, C++20, Rust, Go, Python 3, JavaScript, TypeScript, or Lua.

Working with other codebases

When you compile a folder or a file with import statements, Steel keeps every module as its own file instead of flattening the project into one giant output. Pass --bundle if you specifically want a single standalone file. 

steel compile myproject cpp
steel compile myproject ts

myproject_cpp/
  steel_rt.hpp
  world.hpp, world.cpp
  main.cpp

myproject_ts/
  tsconfig.json
  world.ts
  main.ts

C++20 output uses standard library RAII types (std::variant, std::shared_ptr, std::function, native exceptions) and compiles cleanly under g++ -std=c++20 -Wall -Wextra -Wpedantic. TypeScript output emits inferred types with strict: true and no @ts-nocheck.

Targets

Language Flag Output
C (C11) c .h / .c modules + steel_rt.h, optional --bin --release
C++ (C++20) cpp #pragma once .hpp / .cpp modules + steel_rt.hpp
Rust rust mod files + steel_rt.rs + main.rs, optional --bin --release
Go go package main .go files + go.mod
Python 3 python Separate .py modules
JavaScript js CommonJS .js modules
TypeScript ts Typed .ts modules with export/import + tsconfig.json
Lua lua Lua 5.4 modules returning exported tables

Install

On Windows, download Steel-v1.0.0-Windows-x64.zip from GitHub Releases and run steel-setup.exe. To build from source with Rust: 

git clone https://github.com/skrdmchi-dev/steel.git
cd steel
cargo build --release
cargo test

Basic commands

steel                           # interactive REPL
steel run app.steel             # run directly
steel compile app.steel cpp     # compile to C++20
steel compile app.steel ts      # compile to TypeScript
steel compile app.steel all     # compile to all 8 targets
steel test examples/tests.steel # run unit tests
steel check app.steel           # syntax and type check
steel fmt app.steel             # format source
