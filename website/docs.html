Documentation

Language reference and CLI usage for Steel v1.0.

Install

On Windows, download Steel-v1.0.0-Windows-x64.zip from GitHub Releases, extract it, and run steel-setup.exe.

To build from source with Cargo:

git clone https://github.com/skrdmchi-dev/steel.git
cd steel
cargo build --release
cargo test

Syntax

Steel uses curly braces with optional semicolons and optional let. First-time assignments declare variables automatically, while let and const remain valid when you want explicit declarations.

name = "Steel"
const version = 1.0
active = true
items = [1, 2, 3]
cfg = { host: "localhost", port: 8080 }

print("Running ${name} v${version}")

Control flow supports if / else if / else, while, for i in 0..10, for x in arr, break, continue, ternary a ? b : c, null coalescing a ?? b, and try / catch / throw.

Functions & closures

Functions support block bodies, single-expression bodies (=), default parameters, arrow lambdas (=>), pipes (|>), and stateful closures across all 8 targets.

fn double(x) = x * 2
fn add(a, b = 10) = a + b

score = 5 |> double |> add

fn make_counter(start) {
    count = start
    return step => {
        count += step
        return count
    }
}

cnt = make_counter(10)
print(cnt(5), cnt(3)) // 15 18

Classes & inheritance

Classes support init constructors, methods, this, and multi-level extends inheritance across all targets.

class Animal {
    init(name) { this.name = name }
    kind() = "animal"
    describe() = this.kind() + ":" + this.name
}

class Dog extends Animal {
    init(name) { this.name = name }
    kind() = "dog"
}

d = new Dog("Rex")
print(d.describe()) // dog:Rex

Multi-file projects

Split code across files and import them with import "file.steel". Compiling a folder or a file with imports emits separate target modules in <project>_<target>/ by default. Pass --bundle to combine everything into a single file.

steel compile myproject cpp
steel compile myproject ts
steel compile myproject c --bundle
